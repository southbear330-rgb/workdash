# 팀 근무시간 대시보드 (WorkDash)

## 사용 방법

### 1. 팀원 설정
- 좌측 메뉴 **"팀원 관리"** → 이름, 색상, 기본 출퇴근시간 설정
- 최대 14명

### 2. 데이터 입력
- **전산 데이터 붙여넣기**: 전산에서 복사한 데이터를 그대로 붙여넣고 팀원 선택 후 "가져오기"
- **직접 입력**: 날짜, 팀원, 출퇴근시간 입력

### 3. 확인
- **대시보드**: 오늘·이번 주 현황 요약
- **타임라인**: 요일별 근무 시간대 및 겹치는 구간 시각화
- **근무 통계**: 팀원별 주간/월간 근무시간 표

### 데이터 저장
- 브라우저 localStorage에 저장됩니다
- "↓ 내보내기" 버튼으로 JSON 파일로 백업 가능
- ⚠️ 브라우저 캐시 삭제 시 데이터가 사라질 수 있으니 정기적으로 내보내기 권장
